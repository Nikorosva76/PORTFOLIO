## 1) Омниканальный AI-бот для интернет-магазина чая и кофе (Python) — Site Widget / Telegram / Avito + RAG по прайсу

**Описание:** чат-бот для обработки входящих обращений и “холодных” лидов 24/7 с получением контактных данных и передачей лида в **1С:CRM**.

- **Каналы:** виджет на сайте, Telegram, Avito  
- **Интеграции:** 1С:CRM  
- **Нагрузка:** ~100–1000 обращений/день  
- **Handover на оператора:** нет

**Ключевые функции**
- Ответы 24/7 по ассортименту, условиям, доставке и оплате.
- Квалификация запроса и перевод диалога к сбору контактных данных.
- Передача лида + контекста общения в 1С:CRM.
- **RAG по прайсу/каталогу:** поиск релевантных позиций, выдача точных характеристик/цен без “додумывания”.

**Моя роль / выполненные задачи**
- Архитектура бота и единая логика для нескольких каналов.
- Проектирование промптов (тон, политика ответов, лидогенерация).
- Реализация RAG: подготовка данных прайса, retrieval-логика, формат grounded-ответов.
- Интеграция с 1С:CRM для передачи контактных данных и контекста запроса.
- Обработка неполных запросов и уточняющие вопросы.

**Эффект**
- Сокращение трудозатрат на обработку входящих сообщений.
- Поддержка **24/7** вместо **8/5**, снижение потерь обращений вне рабочего времени.

## 2) Email → Google Calendar ассистент (Make/Integromat) — текст + скриншоты

**Описание:** автоматизация, которая получает инструкции по событиям из email и управляет **Google Calendar**: создаёт, корректирует и отменяет события.

- **Платформа:** Make (Integromat)  
- **Интеграции:** Email, Google Calendar  
- **Handover:** нет

**Ключевые функции**
- Парсинг текстовых инструкций (create/update/cancel).
- Обработка **скриншотов** со смартфона/ПК: извлечение параметров события из изображения.
- Создание/перенос/отмена событий в Google Calendar.
- Сопоставление с существующими событиями для корректных обновлений без дублей.

**Моя роль / выполненные задачи**
- Проектирование сценария Make: триггеры, маршрутизация действий, обработка ошибок.
- Нормализация даты/времени/таймзоны и формирование структуры события.
- Логика поиска совпадений и безопасного обновления/отмены.
- Fallback-ветки при неполных инструкциях.

## 3) Telegram-бот для контроля питания диабетика — персонализация + RAG по личным данным

**Описание:** персональный бот, который собирает данные о питании и активности, анализирует фото еды, даёт рекомендации и накапливает историю для анализа.

- **Канал:** Telegram  
- **Хранение:** JSON  
- **Handover:** нет

**Ключевые функции**
- Сбор событий: питание, активность, заметки пользователя.
- Анализ фото еды и оценка калорийности.
- Персональные рекомендации по питанию и активности.
- Накопление и анализ истории (сводки, динамика).

**RAG-компонент**
- **RAG по личным данным:** вес/рост/медицинские ограничения и другие параметры используются как “контекстная база” для персональных рекомендаций.

**Моя роль / выполненные задачи**
- Проектирование JSON-структуры данных (события, атрибуты, даты, агрегаты).
- Диалоговые сценарии: быстрый ввод, уточнение, исправления записей.
- Реализация персонализации через retrieval по профилю пользователя.
- Правила безопасности: ограничения на категоричные медицинские утверждения (без назначения лечения).

## 4) OpenAI-assistant для написания статей “в стиле автора” — БЗ эталонных образцов

**Описание:** ассистент, генерирующий статьи по заданной теме в стиле конкретного автора на основе эталонных текстов.

- **Компонент:** OpenAI Assistant  
- **Handover:** нет

**Ключевые функции**
- Генерация статей по ТЗ (структура, объём, тезисы).
- Соблюдение стилистики (лексика, тон, манера изложения).
- Вариативность: несколько черновиков/вариантов подачи.

**База знаний**
- **БЗ из эталонных образцов:** корпус текстов автора для удержания “голоса” и типовых приёмов.

**Моя роль / выполненные задачи**
- Проектирование system-prompt и формата результата (outline → draft → polish).
- Механика “style grounding”: опора на эталоны, снижение стилевого дрейфа.
- Контроль качества: соответствие теме, структурность, снижение “воды”.
